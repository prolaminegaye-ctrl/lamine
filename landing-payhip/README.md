## Mise en ligne (Netlify)

Déposer à la racine du site (drag & drop dans l'espace Netlify) :

1. `index.html` ;
2. `cover-ia-sous-controle.jpg` ;
3. `cover-front.png` est déjà présent sur le site — rien à faire.

Après mise en ligne, cliquer une fois sur chaque bouton « Acheter » pour vérifier
que chacun ouvre la bonne page produit Payhip.
